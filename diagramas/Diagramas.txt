(Diagrama de secuencia)
sequenceDiagram
    autonumber
    actor Jugador as 🎮 Godot (Cliente)
    participant API as 🌐 FastAPI (Rutas)
    participant Service as ⚙️ Lógica (Servicios)
    participant DB as [(🗄️ NeonDB)]

    Jugador->>API: POST /alianzas/crear (JSON + JWT)
    API->>API: Valida Token y Esquema Pydantic
    API->>Service: Llama a crear_alianza(datos)
    Service->>DB: Consulta: ¿Existe el nombre?
    DB-->>Service: Respuesta: No existe
    Service->>DB: Consulta: ¿Saldo suficiente?
    DB-->>Service: Respuesta: Sí (Ej: 10,000 Minerales)
    Service->>DB: Inicia Transacción ACID
    Service->>DB: INSERT Alianza y MIEMBRO_ALIANZA (Líder)
    DB-->>Service: Transacción Exitosa (Commit)
    Service-->>API: Devuelve objeto Alianza
    API-->>Jugador: HTTP 200 OK (Datos de la Alianza)
------------------------------------------------------------------------
